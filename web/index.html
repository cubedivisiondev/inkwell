How to shoot it

Flat light beats bright light. Window light on an overcast day is ideal. Direct sun casts a hard gradient across the page. Do not use flash, which blows the highlight and flattens the very gradient this needs.

Shoot square to the page and fill the frame. Perspective is not corrected, and more pixels on the stroke make a better edge. Any paper works. Grain, texture and tint are all handled.

Nothing is uploaded. There is no server and no account. The photograph is decoded in this tab and discarded when it closes. A signature is a credential, and credentials should not travel.

Vector output for foil and die work, plus print geometry for seven card sizes, live in the command line tool. pip install inkwell-ink.
